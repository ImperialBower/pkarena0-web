## The embed build

This release adds `<pk-table>`: the table as a custom element for other
people's pages. Unpack the tarball beside your page and write two lines:

```html
<script type="module" src="pk-table/pk-table.js"></script>
<pk-table seed="42"><img src="table.png" alt="A poker table"></pk-table>
```

- Nothing is fetched until **Deal**; the picture is what script-off, `file://`
  and paper readers get, and what stays if the engine will not load.
- Each element is its own game; every request goes to the module's own
  directory; no fonts, no CDN.
- `MANIFEST.sha256` lists every file's digest.

Full details, the attribute table and the events are in the README
(§ Embedding) and [EPIC-56](https://github.com/ImperialBower/pkarena0-web/blob/v0.2.1/docs/EPIC-56_Embed_Build.md).
No game logic, bot data or difficulty behaviour changed; the action row's
logic moved to `www/js/actions.js` with a parity test.
