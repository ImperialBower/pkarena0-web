# pkarena0-web v0.2.0

**Released:** 2026-10-18
**Engine:** [`pkcore`](https://crates.io/crates/pkcore) `0.12.1`

## Overview

`pkarena0-web` is a single-player No-Limit Texas Hold'em table in your
browser. You face eight AI bots. The engine is Rust compiled to WebAssembly
and served as one static page — no server, no account, no install.

`v0.2.0` makes two changes:

- **New license: `MIT OR Apache-2.0`** (was `GPL-3.0-or-later`). Same terms as
  `pkcore`. Pick either license.
- **A feature roll-up.** This is the first release note since `v0.1.0`, so the
  list below covers everything the app does today.

No game logic, WASM exports or bot data changed in this release.

## Features

### Play

- **No-Limit Hold'em vs. eight bots.** You sit at seat 0 with $10,000. Blinds
  are $50 / $100.
- **Raise controls:** slider, number box, and **MIN / POT / ALL-IN** shortcuts.
- **Pre-action Check/Fold:** arm a Check/Fold while the bots act.
- **New Table:** walk away to fresh bots and a fresh stack without busting out.
- **Lifetime P&L** in the score bar. It survives reloads and has a Reset
  button in Settings.
- **Seat HUD:** live VPIP / PFR / AF stats for each opponent.
- **Mobile layout** with a dock that stays reachable when a session ends.

### Bots

- **Three difficulty tiers:** Weak, Standard, Strong. Each is a YAML bundle in
  `data/bots/`, checked by `make validate-bots`.
- **Position-aware play** for every archetype.
- **Real equity and outs** on the Standard and Strong tiers. Strong also uses
  the preflop solver chart.
- **Adaptive bots** (toggle). They adjust to how you play after enough hands.
- **Arena tab:** watch eight bots play each other. `make bench-tiers` uses it
  to measure chips/100 per tier.

### Look and sound

- **Four themes:** Midnight Pro, Engine Terminal, Table Stakes, Organic.
- **2-color / 4-color deck** toggle and **table / list** seat view.
- **Hand log** drawer showing every player's hole cards after the hand.
- **Game Speed** slider.
- **Voice narration** (experimental) through browser `SpeechSynthesis`.

### Review

- **Export YAML:** download the hand history of the whole session.
- **Replay:** step through hands with Prev / Next. Load the current session or
  upload a YAML file.
- **STATE / View game state (JSON):** inspect the live game state.

### Under the hood

- **Rust + `wasm-bindgen`.** Game state lives in Rust `thread_local!`
  singletons. JavaScript calls a few exports and reads JSON back.
- **Small download:** about 472 KB brotli (2.1 MB raw).
- **Tests:** 30 Rust tests, 5 bot-bundle parity fixtures, and 65 Playwright
  specs on every PR.
- **CI/CD:** GitHub Actions builds the WASM and deploys to GitHub Pages.
